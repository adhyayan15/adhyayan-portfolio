# Adhyayan Tiwari — Portfolio

An editorial personal engineering portfolio with interactive educational demonstrations, project case-study links, human-centered robotics research, leadership, and writing.

## Stack
Next.js App Router, React, CSS.

## Run locally
1. Install Node.js 20.9 or newer.
2. Run `npm install`
3. Run `npm run dev`
4. Visit http://localhost:3000

## Deploy on Vercel
1. In Vercel click **Add New → Project**.
2. Import `adhyayan15/adhyayan-portfolio` from GitHub.
3. Choose **Next.js**, set the root to `./`, and deploy.
4. Future pushes to the `main` branch trigger rebuilds automatically.

## Editorial integrity
Project summaries are drawn from the real public repositories. The scheduler and decade-counter widgets are browser illustrations; the GPU chart displays a documented single-device result, not a live measurement. The NanaBot material describes research in progress.
